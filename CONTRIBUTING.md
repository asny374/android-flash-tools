# Contributing

Run assembleDebug testDebugUnitTest lintDebug before submitting changes. Protocol changes need independent wire-format fixtures, partial-read/timeout handling and connection-lifecycle tests. Do not test destructive writes on irreplaceable data.

When reporting issues, include app version, host/target Android versions, USB/TCP mode and reproduction steps. Redact serial numbers, IPs, file paths and personal log contents before attaching logs.

Original code has no project-wide license yet; discuss licensing with the maintainer before contributing substantial code.
